# Criptografia-em-JS# 🔐 Criptografador em JavaScript

Projeto desenvolvido para uma **atividade avaliativa** utilizando **HTML e JavaScript**.

O programa utiliza o conceito da **Cifra de César** para criptografar uma frase. O usuário informa a frase e a quantidade de casas que deseja deslocar no alfabeto.

## ⚙️ Como funciona

1. O usuário informa uma frase.
2. Informa o número de casas que cada letra deverá ser deslocada.
3. O programa percorre cada caractere da frase.
4. As letras são deslocadas de acordo com o número informado.
5. Quando o deslocamento ultrapassa o final do alfabeto, ele retorna ao início.
6. A frase criptografada é exibida na página.

Caracteres que não são letras não são alterados.
